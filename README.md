# Mobile Customer Sentiment Analysis & Strategy

## Overview
This project uses Natural Language Processing (NLP) to analyze customer sentiments and feedback regarding mobile phones. The goal is to uncover key customer pain points, feature preferences, and general sentiment trends to inform future product design and shape marketing strategies.

## Project Structure
- `*.ipynb` - Jupyter notebook containing data preprocessing, exploratory data analysis (EDA), and NLP sentiment modeling.
- `*.csv` - Dataset containing customer reviews and feedback.
- `requirements.txt` - List of required Python packages to run the project.

## Key Features & Workflow
- **Data Preprocessing**: Cleaning text, tokenization, removing stop words, and lemmatization.
- **Sentiment Classification**: Categorizing reviews into positive, negative, and neutral sentiments using NLP techniques.
- **Strategic Insights**: Translating sentiment scores into actionable recommendations for product features and target marketing.
